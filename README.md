# Tang Chee Hong — résumé website

GitHub Pages serves the production build from this repository root. The editable React and TypeScript project is in `site-source/`.

To update the live files locally, install dependencies and run `site-source/scripts/publish-build.ps1` from PowerShell. The script builds the project and copies the generated page, PDF, app assets, favicon and character pose frames into this directory.

The previous profile remains in Git history. GitHub Pages should continue serving the `master` branch from its root; this replacement keeps that publishing setup.
